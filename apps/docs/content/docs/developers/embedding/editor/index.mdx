---
title: Editor
description: Embedded authoring is not available in TerraPay Sign.
---

TerraPay Sign does not support embedded authoring. The embedded editor, the presign tokens that authorised it and the editor SDK components have been removed, so documents, templates and envelopes are created and edited in the TerraPay Sign application or through the [API](/docs/developers/api/documents).

[Embedded signing](/docs/developers/embedding) is still supported.
